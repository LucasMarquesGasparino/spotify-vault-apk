① Crie seu app no Spotify

  1. Acesse developer.spotify.com/dashboard e faça login (precisa Premium)
  2. Clique Create app → nome: Spotify Vault → marque Web API
  3. Em Redirect URIs adicione exatamente:
    spotifyvault://callback
    http://127.0.0.1:8888/callback
  4. Copie o Client ID e cole abaixo.

② Login Spotify (PKCE - sem server)

Sincronização

A API só devolve as 50 últimas faixas. O app busca automaticamente às 9h, 12h, 15h, 18h e 21h30 Brasília (America/Sao_Paulo) via alarme exato e evita duplicatas. Se tocar >50 músicas entre um intervalo sem sync, pode perder.

Importar histórico estendido (ZIP ou JSONs)

Em spotify.com/account/privacy → Baixar dados → solicite Extended streaming history. Você receberá um ZIP com Streaming_History_Audio_*.json e endsong_*.json. Selecione o ZIP direto ou os JSONs extraídos - o app lê ambos.

Backup local

Banco é SQLite local autônomo (spotify_vault.db) via bridge nativa. Nada vai pra nuvem.

Sobre rejeição / skip

O endpoint recently-played só inclui faixas tocadas >30s, sem ms_played. Pulso antes de 30s não entra. Para métrica real de skip (quanto % da música ouviu), só com o histórico estendido que tem ms_played e reason_end = trackdone / fwdbtn / backbtn. Depois de importar, os Insights mostrarão taxa de skip precisa.
